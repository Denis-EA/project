# Урок 1. Введение в тестирование

!!! info "Цель урока"
    Понять, кто такой тестировщик, какие виды тестирования бывают и как строится жизненный цикл ПО.

## Кто такой тестировщик?

Тестировщик (QA Engineer) — это специалист, который проверяет, соответствует ли продукт требованиям и ожиданиям пользователей. Его задача — найти баги **до** того, как их найдут клиенты.

## Виды тестирования

| Вид | Описание |
|:----|:---------|
| Функциональное | Проверка, что продукт работает по требованиям |
| Нефункциональное | Производительность, безопасность, удобство |
| Регрессионное | Проверка, что старый функционал не сломался после изменений |
| Исследовательское | Тестирование без готовых сценариев, "свободный поиск" |

## Жизненный цикл ПО

```mermaid
graph LR
    A[Анализ требований] --> B[Дизайн]
    B --> C[Разработка]
    C --> D[Тестирование]
    D --> E[Релиз]
    E --> F[Поддержка]
```
